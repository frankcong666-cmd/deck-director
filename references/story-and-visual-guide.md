# Story and visual guide

## Narrative patterns

Choose a pattern that fits the task instead of forcing a generic agenda.

| Situation | Useful narrative movement |
|---|---|
| Product or design case study | Problem, principle, evidence, deeper mechanism, conclusion |
| Recommendation | Context, decision criteria, options, recommendation, next step |
| Research or academic talk | Question, method, findings, interpretation, implication |
| Project update | Goal, progress, evidence, risk, decision needed |
| Pitch | Audience problem, opportunity, solution, proof, ask |

The close should answer the opening. Aim for one short thought that the audience can repeat after the presentation.

## Visual direction prompts

Translate subjective requests into decisions:

| User language | Possible design response |
|---|---|
| Minimal | Strong negative space, sparse copy, restrained palette, one focal point |
| Cinematic | Full-bleed imagery, dramatic light, large scale contrast, paced reveals |
| Editorial | Precise grid, confident typography, cropped images, generous margins |
| Technical | Evidence-first layout, annotated diagrams, systematic spacing, calm palette |
| Warm or human | Human-scale imagery, tactile color, natural light, conversational copy |
| Premium | Controlled palette, ample space, refined typography, fewer elements |
| Playful | Expressive color, surprising scale, intentional visual rhythm, simple copy |

These are starting points, not fixed styles. Combine and adapt them to the topic, audience, and the user's references.

## Full-bleed image rule

If a full-bleed visual matters, protect it. Generate or crop the image with intentional copy space; do not hide the subject beneath a large rectangle. Use a light gradient only when it improves legibility without changing the evidence or flattening the composition.

## Closing-line test

A conclusion usually works when it:

1. Follows directly from the evidence shown.
2. Uses plain, speakable language.
3. Fits on the slide as a visual statement rather than a paragraph.

Example forms include a short principle, a reframed question, or a practical implication. Choose the form that matches the talk instead of reusing a stock slogan.
